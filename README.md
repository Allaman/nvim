**Terminal**: [Kitty](https://github.com/kovidgoyal/kitty)

**Multiplexer**: [Tmux](https://github.com/tmux/tmux/) (I am old-school 😀)

**Font**: [MonoLisaCode](https://www.monolisa.dev/)

**Neovim Theme**: [Neovim's default theme](https://github.com/neovim/neovim/pull/26334)

> [!NOTE]  
> You can use this configuration for inspiration but I wouldn't recommend to use it as is. Roll your own configuration and extend it whenever needed.

Check out my [blog post](https://rootknecht.net/blog/debloating-neovim-config/) to learn more about the reasons behind this big change. You can find the previous version in the [v1](https://github.com/Allaman/nvim/tree/v1) branch.

A Docker image from this configuration is automatically built `docker run -it --name nvim --entrypoint /bin/bash --rm allaman/nvim`
